## 0.12.0 (2026-08-29)

### Fixed
- **Critical: the wheel contained no Python modules.** `[tool.hatch.build.targets.wheel]`
  declared `packages = ["src/qgis_mcp"]` against a flat layout with no `src/`. Hatchling
  emitted a wheel holding only `dist-info`, so `pip install qgis-mcp` installed none of the
  connector's code and the `qgis-mcp-server` console script imported a package that was never
  shipped. Editable installs masked it. (N47)
- **Layer B was inert.** `API/` and `scripts/registry.json` did not exist, so `search_qgis_api`,
  `list_qgis_api_categories`, `qgis_function_registry_query` and `register_verified_qgis`
  answered every call from empty state while occupying tool surface. `doc_search` and
  `function_registry` both swallow the missing file and degrade silently. (N36)
- `tests/check_layer_b.py` passed 15/15 with the payload absent — it tested the modules against
  temp fixtures and never asserted that the shipped payload exists. Now asserts it. (N48)
- `doc_search._parse_file` indexed a file's preamble as a section, so any text before the first
  `#` heading became a searchable "function" with no syntax and no description.

### Added
- `API/` — 39 PyQGIS reference sections across 7 categories, generated by
  `scripts/gen_api_docs.py`, which resolves every name through the upstream Sphinx inventory
  before fetching, so an upstream rename is a build error rather than a fabricated section.
- `scripts/registry.json` — 21 verified PyQGIS call patterns. Each one is **executed** against a
  real QGIS by `scripts/verify_registry.py`; an entry that does not run is not written.
- `qgis_mcp/aiconnect-capabilities.json` — 45-entry tier-2 capability index (21 verified,
  24 documented), generated by `scripts/gen_capabilities.py`, reached through `execute_code`.
  Measured: +4.8 pt weighted coverage and 7 of 10 tier-2 tasks at **zero** added session tokens.
- 5 more code templates (6 → 11): reproject, dissolve by attribute, zonal statistics, labelling,
  layout export. Their processing algorithm ids are resolved against the real registry.
- `manifest.tool_tiers.core` — 31 tools, measured, not guessed. Same effective coverage as
  listing all 125 (98.6%) at 26% of the tokens, stranding nothing.
- `manifest.tool_index` — `execute_code` as the exec hatch, floor 5.5.

### Changed
- `manifest.package.include` now declares `API`, `scripts/registry.json` and
  `templates/templates.json` as **files**, so a missing payload fails the build instead of
  shipping six discovery tools that answer from empty state.
- `raster_calculator` and `spatial_join` descriptions rewritten with task vocabulary (NDVI,
  point-in-polygon). Measured: this alone took the tier-1 set from 2 stranded tasks to 0.
